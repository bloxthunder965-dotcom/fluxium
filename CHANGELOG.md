# Changelog

## [2.0.1] — Minecraft 26.1.2

Client workload-management framework (not Potato Mode).

### Added
- Flux Scheduler, Adaptive Rendering, Smart Chunk Pipeline
- Memory / Logic / Network optimizers, Frame-Time Protection
- Predictive modes: EXPLORING / COMBAT / BUILDING / IDLE
- `/fluxium` diagnostics and benchmark commands
- Config `config/fluxium.json`

### Removed vs 2.0.0
Forced low graphics settings (Fast, RD=8, particles minimal, VSync off, etc.)
