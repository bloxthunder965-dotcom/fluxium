# Fluxium 2.0.1

**Client-side performance optimization mod for Minecraft 26.1.2 (Fabric)**

> Don't make Minecraft do less. Make Minecraft do the right work at the right time.

## Requirements

- Minecraft **26.1.2**
- Fabric Loader **>= 0.19.5**
- Fabric API
- Java **25+**

## Commands

| Command | Action |
|---------|--------|
| `/fluxium debug` | Toggle diagnostics + metrics dump |
| `/fluxium diagnostics` | ACTIVE / INACTIVE report |
| `/fluxium benchmark start` | Start recording samples |
| `/fluxium benchmark stop` | Stop and print results |
| `/fluxium status` | Live metrics dump |
| `/fluxium counters reset` | Reset counters |
